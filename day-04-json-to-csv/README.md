# Day 4 — JSON-to-CSV Converter

## What this is

A Python script that pulls user data from a public REST API
(jsonplaceholder.typicode.com/users), flattens the nested JSON each user
comes back as, and writes the result to a clean CSV file.

## Why flattening was needed

Each user record isn't flat — address is itself a nested object, and inside
it, geo is nested one level deeper again (lat/lng). company is a separate
nested object too. A CSV can only hold flat rows and columns, so those
nested fields had to be turned into their own columns (address.street,
address.geo.lat, company.name, etc.) before the data could be written out.

## How it works

- requests.get(url) fetches the raw JSON from the API.
- response.raise_for_status() checks the HTTP status code and stops the
  script immediately if the request failed, instead of silently continuing
  with missing or broken data.
- pd.json_normalize(data) does the actual flattening — it walks every
  nested dictionary and turns each nested field into its own column, joining
  parent and child names with a dot (address.geo.lat).
- df.to_csv(output_path, index=False) writes the flattened result to disk.
  index=False stops pandas from adding its own row-number column.

## Result

10 users, 15 flattened columns, written to users.csv. Verified by comparing
the flattened columns and values against the original raw JSON for the
first user before trusting the rest of the output.

## Files

- fetch_users.py — the script
- users.csv — the flattened output (generated by running the script)

## How to run

python fetch_users.py
